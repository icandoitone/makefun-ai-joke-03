# AI Joke — "My Fault"

Entry for make.fun `ai-joke-03`.

One joke, one line, about AI coding agents:

> My AI coding agent fixed my bug in three seconds, then spent three hours explaining why it was my fault.

`main.py` writes `entry.txt` to `/output/entry.txt`, byte-identical on
every run, and self-checks the 1–280 character rule. The joke is 104
characters.

License: MIT.

## Why this joke

The judge weighs, in order: a joke about AI coding agents, a real
surprise at the end, a truth developers recognise, economy, and
freshness. This one has all five: the agent is the subject; the
punchline flips the expectation (three seconds to fix, three hours to
blame me); any developer who has watched an agent lecture them
recognises it at once; it lands in a single line with no wasted word;
and the angle — the agent as a mansplainer who bills you in time —
is not a stock joke.
